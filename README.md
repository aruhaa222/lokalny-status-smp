# Локальный статус СМП

Локальное веб-приложение для формирования описания объективного статуса. Данные вводятся и обрабатываются в браузере; не используйте приложение для хранения или передачи идентифицирующих данных пациентов.

## Публикация

Главная страница сайта должна находиться в корне репозитория в файле `index.html`.

Workflow GitHub Actions из `.github/workflows/pages.yml` публикует содержимое репозитория на GitHub Pages при push в ветку `main`.

1. Откройте **Settings → Pages** и выберите **GitHub Actions** как источник публикации, если это ещё не настроено.
2. После успешного запуска workflow адрес сайта появится в настройках Pages и в результате deployment job.

Важно: если сайт опубликован, его могут открывать другие люди. Не вносите реальные персональные или медицинские данные пациентов. Инструмент является вспомогательным прототипом, не заменяет клиническое решение и требует профессиональной проверки.
